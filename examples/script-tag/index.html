小而完整的浏览器能力。

页面不可见时自动暂停；发生跨域导出错误时仅跳过当前帧，后续更新不受影响。

01 / VIEWPORT

只截取你看到的部分

按当前滚动位置裁剪，不会把整张长页面塞进 16 到 64 像素的图标。

02 / PNG

三档有效尺寸

从 16x16 到 64x64，统一生成自包含 PNG data URL，无需额外静态资源。

03 / CONTROL

随时恢复原图标

控制器的 stop() 会取消任务，并将 favicon 恢复为初始化之前的状态。

SCRIPT TAG

不需要打包器。

加载单个 IIFE 文件后，直接调用唯一的公开方法即可开始。

阅读中文文档
<script src="/assets/live-favicon.iife.js"></script>
<script>
  const controller = LiveFavicon.initFavicon(500);
  // controller.stop()：停止并还原图标
</script>
